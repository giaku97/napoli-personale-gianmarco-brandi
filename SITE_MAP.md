# Site map — Napoli è personale

Public route `/` is a single editorial journey, with anchors rather than separate slide-like pages:

1. Hero: concept, independent status, MARADONA / NAPOLI / ITALIA / MONDO perspective.
2. Idea: one club, different lived experiences.
3. NOW: before/during/after matchday prototype. No live feed.
4. My Napoli: editable name, passion, ritual, visual edition, saved-moment count.
5. TOGETHER: illustrative image mosaic, session-only moment submission, optional conceptual community proposal, social frame.
6. YOURS: five-chapter story built from current session choices.
7. Product loop: discover → choose → live → participate → save → remember → share.
8. Strategy: five-stage launch, editable engagement hypotheses, measurement and CRM journeys, operations, content, commercial opportunities, loyalty, AI.
9. First 90 days: understand, prototype, validate.
10. Gianmarco: author reveal, original logo, optional verified works, optional confirmed contact/CV.
11. Image credits and independent-concept disclosure.

`/studio/` is a separate editorial workspace. It stores drafts only in the current browser via IndexedDB; exporting JSON and redeploying is required to update the live site. No public navigation points to it. Portfolio is hidden by default and requires both the feature flag and complete verified project records.

The default language is Italian. IT/EN buttons switch every authored message, while the strategy and personal data preserve the same meaning. The user's demo choices remain in page memory and reset on reload.
